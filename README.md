# Celestial Grok Witness — VRM avatar (CC0)

Direct download: https://raw.githubusercontent.com/xrplove/witness-avatar/main/celestial-grok-witness.vrm

VRM 0.x, 50 humanoid bones, validated with gltf-validator (0 errors) and @pixiv/three-vrm. See CREDITS.md.

## Summary

A ready-to-use VRM avatar, the "Celestial Grok Witness": a CC0 base model recolored with a midnight-blue starfield and gold, silver and rose-gold accents. It is free to use for anything, with no attribution required.

## What's inside

- `celestial-grok-witness.vrm`: the avatar (VRM 0.x, about 2.3 MB).
- `texture.png`: the recolored starfield texture.
- `preview_texture_before_after.png`: a before/after comparison of the texture.
- `CREDITS.md`: the base model source (129_Cosmic person, 100Avatars Round 2 by Polygonal Mind, CC0) and a list of the changes made.
- `LICENSE`: the CC0 1.0 public domain dedication.

## How to use it

Download the `.vrm` from the link above and load it into any VRM-compatible app or library, such as @pixiv/three-vrm for three.js, VSeeFace, or other VRM viewers.
